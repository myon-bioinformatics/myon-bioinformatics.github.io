DRAgoWing

Renders research records as Plotly.js HTML reports and proposition tables, with optional headless-Chrome PNG/SVG export and no Python plotting libraries.

▶ 実行例

📦
myon-bioinformatics/Aoi @ 719ed6e
⌨️
python3 -S -m dragowing --help
↩️
exit 0
usage: python3 -m dragowing [-h] --results RESULTS --out OUT [--id IDS]
                            [--column COLUMN] [--team-order TEAM_ORDER]
                            [--cond CONDS] [--breakdown BREAKDOWN]
                            [--breakdown-keep BREAKDOWN_KEEP]
                            [--chrome CHROME]
                            [--overlap-backend {native,stdlib}] [--png]
                            [--svg] [--embed]

記録された結果を HTML にする。判定はやり直さない。

options:
  -h, --help            show this help message and exit
  --results RESULTS     season.jsonl と propositions.jsonl があるディレクトリ
  --out OUT             HTML の出力ディレクトリ
  --id IDS              この命題だけ。繰り返せる。省略すると全部
  --column COLUMN       球団×年に置く数値列。既定は wins_vs_pythag
  --team-order TEAM_ORDER
                        球団×年で上から並べる球団の記号（カンマ区切り）。例: d,g,s 。省略すると記号順
  --cond CONDS          重なりの条件。col,op,値（JSON）。例: rd,>,0 。繰り返せる（B クラスを含めて 2〜8
                        個）。省略すると if の先頭2件と B クラス
  --breakdown BREAKDOWN
                        重なりの内訳を分ける列。team、team_name、league、season、upper_half
                        のどれか。既定は team
  --breakdown-keep BREAKDOWN_KEEP
                        内訳で「その他」にまとめず別の色で残す値。繰り返せる。例: d（件数にかかわらず残す）
  --chrome CHROME       Chrome/Chromium の実行ファイル。省略時は CHROME / CHROMIUM
                        環境変数、なければ PATH
  --overlap-backend {native,stdlib}
                        重なり計算。stdlib は限定したスカラー列のみ（numpy/polars 不要）。既定は native
  --png                 PNG も書く。Chrome が要る。既定では HTML だけ
  --svg                 SVG も書く。Chrome が要る。既定では HTML だけ
  --embed               index.html に Plotly.js を埋め込む。既定は CDN。propositions.html
                        は Plotly を使わない
