nvd_nist_known_vulns

Single-file, standard-library client for the NVD CVE API 2.0: fetches known vulnerabilities for CPE 2.3 names and emits deterministic JSON Lines. CI-tested on Python 3.9–3.14.

🎞️

▶ 実行例

📦
myon-bioinformatics/nvd_nist_known_vulns @ 405fe8b
⌨️
python3 -S nvd_nist_known_vulns.py --help

exit 0
usage: nvd_nist_known_vulns.py [-h] [--silent] [--config CONFIG] [--cpe CPES]
                               [--output OUTPUT] [--timeout SECONDS]
                               [--format {text,json}]
                               [--cvss-v3-severity {LOW,MEDIUM,HIGH,CRITICAL}]
                               [--cvss-v3-metrics CVSS_V3_METRICS]

Fetch known CVEs from the NVD CVE API 2.0 for CPE 2.3 names and write nvd-cve-summary/1 JSONL.

options:
  -h, --help            show this help message and exit
  --silent              Do not print per-CPE progress lines on stderr. Errors
                        are still reported.
  --config CONFIG       UTF-8 INI file with a [cpeName] section, used only
                        when --cpe is omitted. Default: config.ini. A missing,
                        unreadable, invalid, or empty CPE list exits 2.
  --cpe CPES            One CPE 2.3 name to query. Repeat for multiple names.
                        Values are not split on commas. When any --cpe is
                        present, --config is not read.
  --output OUTPUT       Write JSONL to this UTF-8 path, replacing it only
                        after a finished run. Default: stdout. A failed run
                        leaves an existing file unchanged. An output path that
                        cannot be published exits 1.
  --timeout SECONDS     Positive finite per-request socket timeout in seconds.
                        Default: 30.
  --format {text,json}  Failure report on stderr. text (default) prints error:
                        lines for input and runtime failures. json prints one
                        nvd-cli-error/1 object and no progress lines. Success
                        output is always JSONL.
  --cvss-v3-severity {LOW,MEDIUM,HIGH,CRITICAL}
                        Optional NVD cvssV3Severity filter on CVE API 2.0:
                        LOW, MEDIUM, HIGH, or CRITICAL. Filtered output uses
                        filtered_cve records.
  --cvss-v3-metrics CVSS_V3_METRICS
                        Optional NVD cvssV3Metrics filter: a partial or full
                        CVSS v3 vector. Blank values are rejected. The value
                        is trimmed and uppercased.

exit status:
  0  success, including a CPE query that returns zero CVEs
  1  the NVD request failed, or --output could not be published
  2  usage or local input error (flags, config file, or CPE list)

--format json writes one nvd-cli-error/1 object to stderr on failure and
omits progress lines. Success records stay JSONL on stdout or --output.
--format text (the default) writes error: lines for input and runtime
failures. Flag mistakes also include the usage summary.
