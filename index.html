web-ui

このポートフォリオのツールページの見た目と表示部品を、ビルド不要の共通UI部品でそろえています。

  • 見た目の統一：tokens → base → components → themes/modern の CSS 層と ui-* クラス
  • 静的ページ生成：web_ui.py の render_document（HTML文書取込をこれで生成）
  • 他リポジトリのページ取り込み：adopt_document で lab 独自クラスを ui-* に置換し、挙動は元のまま
  • 安全な表示：ui.js の setText（textContent のみ）と prettyJson
  • 画面切替と外部リンク：navigation.js の bindViews（Home / Wiki / Pixiv）と openExternalURL
  • 版の固定：取り込んだ commit と SHA-256 を vendor.lock.json に記録
